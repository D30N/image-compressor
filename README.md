# Image Compressor

Free online image compressor. Compress JPG, PNG and WebP photos right in your browser.

Live: https://d30n.github.io/image-compressor/

## Features

- Compress multiple images at once (drag and drop, or choose files)
- Quality slider
- Target file size in KB, the tool picks the best quality automatically
- Resize by max width, max height, or scale percentage
- Output format: JPG, PNG, WebP
- Before and after size, with percentage saved, plus a preview
- Download one image, or all of them as a ZIP
- English and Malayalam language switch
- 100% client-side. No login, no upload, nothing leaves your browser.
